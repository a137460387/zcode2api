怎么进这个后台 入口地址

本机（这台电脑）直接开下面的地址，不需要密码。要从手机或另一台电脑访问，见下一节。

从其他设备访问

默认只监听 127.0.0.1，别的设备连不上；非本机访问还要求密码。要免密从局域网访问， 两步：① 把监听地址改成 0.0.0.0（需重启）；② 打开「完全免密」。
不想免密也行：在下面「面板访问密码」里设一个密码，其他设备用密码进。或者完全不开放 （保持只监听 127.0.0.1）。注意这个面板能改 API Key、删账号——同一局域网里其他人 也能访问时，等于把凭据管理交出去，所以「完全免密」默认是关的。

面板访问密码

用于从非本机打开本面板。本机访问默认免密（可用 PANEL_LOCAL_BYPASS=0 关闭）。 密码以 scrypt 哈希存在 panel.json，不存明文；改密会吊销所有已登录会话。

对外 API Key

客户端调用 /v1/* 时携带的密钥。保存后立即生效并写回 .env（重启后仍在）。 面板只显示掩码，原文不回显。
